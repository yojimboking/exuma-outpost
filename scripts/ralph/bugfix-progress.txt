# Bug Fix Progress Log

Started: 2026-01-18
Source: BUG_REPORT.md

## Codebase Patterns

- Use `??` not `||` for null/undefined checks (preserves 0 and '')
- Always guard spreads: `const safe = obj ?? {}` before `...safe`
- Early return for empty arrays before array operations
- Stripe API versions don't have suffixes like `.acacia`
- Server-side validation required for all payment amounts

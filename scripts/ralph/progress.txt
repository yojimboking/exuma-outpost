# Ralph Progress Log - OwnerRez Integration
Started: 2026-02-01
Branch: ralph/ownerrez-integration

## Codebase Patterns

### Project Structure
- Next.js 14 App Router
- Components in /components (sections/, chat/)
- Hooks in /hooks
- Lib utilities in /lib
- API routes in /app/api

### Styling
- Tailwind CSS
- Custom colors: ink (#1A1A1A), paper (#FAFAFA), warm-gray
- Framer Motion for animations
- EB Garamond font

### State Management
- React hooks (useState, useEffect, useMemo)
- Custom hooks for complex logic
- No external state library

### API Patterns
- Route handlers in app/api/*/route.ts
- POST for mutations, GET for reads
- Return NextResponse.json()
- Use revalidate export for caching

### Key Constants (lib/constants.ts)
- PROPERTY: name, location, amenities, sleeps 12
- PRICING: $2000/night high, $1750 shoulder, $1500 low, 7 night min
- SERVICES: airport transfer, chef, boat charter, etc.
- BOOKING_MANAGER: Sharell info, WhatsApp number

### Testing Commands
- `npm run build` - Full production build (primary verification)
- `npm run dev` - Local server on :3000

### Migration Context
- Removing broken Sharell AI chat system
- Replacing with OwnerRez-ready mock APIs
- No OwnerRez credentials yet - use mock data
- Keep beautiful custom UI, only backend changes
